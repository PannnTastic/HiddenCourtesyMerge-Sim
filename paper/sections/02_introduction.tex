\section{Introduction}
\label{sec:intro}

In highway merge negotiation, a controlled vehicle must respond to a
merging vehicle whose behavioural style is not directly observable.
In practice, merge vehicles exhibit qualitatively different strategies:
cooperative drivers slow to create a gap for the ego, while non-cooperative
drivers maintain speed and assert priority.
Responding optimally requires estimating the hidden courtesy type online, a
problem that maps naturally to a POMDP
\citep{kaelbling1998planning,kochenderfer2022algorithms}.

Existing evaluation frameworks treat driver behaviour as a fixed parameter or
use naturalistic trajectory data that lacks verified ground-truth latent
labels \citep{leurent_highway_env,lopez2018microscopic}.
This precludes matched counterfactual evaluation: the comparison of policies
that face identical scenarios, differing only in how they exploit the belief
state.
Studies that do model hidden intent
\citep{sunberg2020internalstates,kruse2022uncertainty} do not run such
comparisons with rigorous paired testing and power analysis.

We address these gaps with \textbf{HiddenCourtesyMerge-Sim}: a reproducible,
simulation-only benchmark in which driver courtesy is a precisely controlled
binary latent variable injected via IDM \citep{treiber2000congested} and
MOBIL \citep{kesting2007mobil} parameters at episode start.
We evaluate five policies---four heuristic baselines and a POMCP planning
solver---over $n{=}300$ matched episodes.
We test whether (i)~online Bayesian courtesy inference improves merge safety
over a belief-agnostic rule, and (ii)~UCT planning can exceed the oracle
heuristic ceiling of the action table.
The novelty is the controlled benchmark and diagnostic protocol: ground-truth
latent courtesy labels enable paired counterfactual tests, while the ablations
separate hidden-state value, belief-convergence limits, action-table
expressiveness, reward sensitivity, and planner-specific confounds.

\paragraph{Summary of findings.}
Hidden courtesy is decision-relevant: oracle-heuristic access to the true type
significantly reduces collisions relative to a uniform-prior rule
(10.3\% vs.\ 18.3\%, $p_\text{adj}{=}0.005$, $|h|{=}0.230$).
Online Bayesian inference does not close this gap at $n{=}300$
(belief: 15.0\%, $p_\text{adj}{=}0.33$); a belief-gain sweep localises the
bottleneck in early-window observation quality, not action-table
expressiveness.
A POMCP solver exceeds the oracle-heuristic ceiling (5.0\% collision,
$p_\text{adj}{=}0.014$, $|h|{=}0.204$), indicating within this simulator
that UCT planning over the reward function identifies action sequences the
hand-designed V-shaped caution rule cannot represent, even when that rule has
access to the true courtesy type.

\paragraph{Scope.}
All results are specific to the described simulator.
Claims of significance are stated only where statistically supported; we are
explicit when comparisons are underpowered.
An anonymized review repository will be provided during submission; the
de-anonymized dataset, code, and figures will be released upon acceptance.
